# Q-Sync Download

Download the Windows setup file from the latest release:

https://github.com/aj3/q-sync-download/releases/latest/download/Q-Sync-Setup.exe

## Installation

Run `Q-Sync-Setup.exe` after it downloads.

- Installs per-user; no admin rights required.
- Creates a Start Menu shortcut.
- Updates are delivered automatically from within the app.
